# ecommerce-data-validation-dashboard
End-to-end e-commerce data validation using SQL (DataGrip) with interactive Power BI dashboard insights

🔹 Project Overview

This project demonstrates an end-to-end e-commerce data validation workflow using SQL (DataGrip) and Power BI. The focus was on ensuring pricing accuracy, validating discount calculations, and generating reliable business insights through dashboard reporting.

🔹 Tools & Technologies

SQL (SQLite)

DataGrip

Power BI

CSV Data Processing

🔹 Project Objectives

Validate final price calculations

Detect rounding discrepancies

Implement tolerance-based discount checks

Create reusable SQL views for analysis

Build an interactive business dashboard

🔹 Data Validation Approach

 Recalculated final prices using SQL
 Compared stored vs calculated discount values
 Applied tolerance logic to handle rounding differences
 Identified mismatched records
 Created validation views for reusability

🔹 Power BI Dashboard Features

📊 KPI Cards:

Total Revenue

Total Orders

Average Order Value

Average Discount

📈 Visual Analysis:

Revenue by product category

Monthly revenue trends

Payment method comparison

Interactive category & time slicers

🔹 Key Learnings

Practical implementation of SQL-based data validation

Handling rounding errors using tolerance thresholds

Translating validated datasets into business-ready dashboards

Combining backend validation with frontend analytics

🔹 Why This Project Matters

Accurate data is critical in e-commerce. This project demonstrates how structured SQL validation ensures trustworthy pricing logic before analytics reporting, reducing business risk and improving decision-making confidence.
